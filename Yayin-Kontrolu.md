# HUBRIS web yayın kontrolü

GitHub Pages, main dalının kökünden yayın yapıyor. Son build durumu built olarak doğrulandı. style.css ve sitemap.xml dosyaları da HTTP 200 döndürdü.

## Arama erişimi

- Alan adı kökü https://drafttasarim.github.io/robots.txt HTTP 200 döndürdü.
- Kök dosyada OAI-SearchBot için Allow: / var; dört HUBRIS adresinin taranmasına izin veriliyor.
- Dört HTML sayfasında robots değeri index, follow. Meta noindex ve HTTP X-Robots-Tag engeli görülmedi.
- Her sayfanın canonical adresi kendi yayın adresiyle eşleşiyor.
- GPTBot politikası değiştirilmedi. Tarama izni, dizine eklenme veya ChatGPT önerisi garantisi değildir.

## İçerik ve görünüm

- İletişim ve destek e-postası tüm sayfalarda info@drafttasarim.com.
- Türkçe gizlilik sayfası 1280×720 görünümde; Türkçe destek ve İngilizce gizlilik sayfaları 390×844 mobil görünümde tarayıcıda kontrol edildi. Kontrol edilen görünümlerde yatay taşma yok.
- Gizlilik/Destek bağlantısı, dil geçişi ve destek mailto hedefi doğrulandı.
- İngilizce sayfa ilk görsel kontrolde geçici GitHub hata ekranı gösterdi; yeniden yüklemede doğru sayfa açıldı ve mobil yerleşim doğrulandı.
- Oyun geliştirme aşamasında olarak gösteriliyor. İlk sürüm için yalnızca yerel kayıt planı kesinleşti; reklam, analitik, kullanıcı hesabı ve uygulama içi satın alma seçenekleri henüz belirlenmedi.

## Yayın öncesinde kalanlar

Bu rapor web sayfalarının yayınını kapsar. Oyun kaynak kodu, build veri akışları veya App Store gizlilik yanıtları doğrulanmış sayılmaz. Gerçek build ve kullanılacak hizmetler kesinleştiğinde gizlilik metni yeniden kontrol edilmeli. Bu işlemde App Store Connect mağaza alanlarına URL kaydedilmedi ve uygulama incelemeye gönderilmedi.
