1. Current status

HUBRIS: Path to Salvation is in development for iOS/iPadOS and macOS. The game has not yet been released on the App Store.

This page describes the plan as of 16 November 2026. Before release, the actual data flows, selected services and App Store privacy disclosures will be checked and reflected here.

2. On-device saves

The first release is planned to store game progress and character development locally on the device used to play. Automatic shared progress between iPhone, iPad and Mac is outside the first-release plan.

Cloud saves and cross-device synchronization are being considered for later development. They are not presented as implemented features.

3. Services not yet selected

Advertising, analytics, user accounts and in-app purchase systems have not yet been determined. No claim is made that these services will be included or that data will be sent to a particular provider.

Once decisions are made, the data involved, purposes, providers and relevant choices will be explained before release.

4. Information shared for support

If you write to info@drafttasarim.com, your email address and the information you include are used to understand, respond to and follow up on your request. The data practices of your and our email service providers also apply.

Share only information relevant to the issue. Do not send passwords, verification codes, identity numbers or bank/card details. Hide personal information in screenshots.

Support correspondence is retained only as needed to resolve the request and meet any applicable recordkeeping obligations. You can request access, correction or deletion of your correspondence using the same email address.

5. This website

This site is hosted on GitHub Pages. Its code includes no advertising, visitor analytics, tracking pixels or cookie-setting scripts. The stylesheet is served with this site, which uses system fonts.

When you open a page, GitHub may process technical data such as IP addresses and request details to provide and secure its hosting service. See the GitHub Privacy Statement. This website notice does not describe the unverified data flows of a future game release.
